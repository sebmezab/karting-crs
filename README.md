# Campeonato Regional Sur — plataforma de karting

Plataforma web para gestionar campeonatos de karting: inscripciones, control técnico (neumáticos y equipos), revisión
post-sesión, sanciones y resultados.

**Estado: Fase 0, demo navegable con datos ficticios.** Especificación: [docs/SPEC.md](docs/SPEC.md).
Guía para desarrollar (personas y agentes): [CLAUDE.md](CLAUDE.md).

```bash
npm install
npm run dev        # http://localhost:5173/karting-crs/
npm run check      # typecheck + lint + tests
```
